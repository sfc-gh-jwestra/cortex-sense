# Cortex Sense

Demos and learning material for Snowflake Cortex Sense.

## Contents

- [Gaming Analytics with Cortex Sense](game_analytics_demo/README.md): a game publisher demo that asks the same ten questions of three Cortex Agents (finance, analyst and Cortex Sense) and compares their accuracy, tool calls and token usage across the catalog and sales domains.
- [Intro workshop](intro-workshop/lab-1-setup-environment.md): three labs that set up the PawPrime data, build a Cortex Sense context with the `/cortex-sense` skill, then evaluate and improve it.
